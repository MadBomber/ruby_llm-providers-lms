    Judgment Examples¶

    Examples 16-20 use LM Studio's decision API with open-source decision models. Each needs at least one decision model; they default to D1 Omni 600M:

    lms get https://huggingface.co/LiquidAI/d1-omni-600M-GGUF
ruby examples/16_judgments.rb
LMS_DECISION_MODEL=clef-flash ruby examples/17_judge_class.rb   # try another model

    The output below is from the author's M2 Max. Your numbers will differ with model, build and machine.

    17 — a reusable judge¶

    TicketTriage < RubyLLM::Judge with the team list passed in at run time (inputs :teams), and the routing rules in plain Ruby:

    TICKET                                         URGENT TEAM        CONF FRUSTR  ROUTE
You charged my card twice this month. I wan...   0.92 billing     0.70    1.9  billing queue, priority
The API has returned 500 errors for an hour...   0.98 technical   0.98    1.8  technical queue, priority
How much would it cost to move our team of ...   0.30 sales       0.77    0.4  sales queue
I forgot my password and the reset email ne...   0.87 accounts    0.91    2.4  escalate to on-call lead
Small thing: the export button tooltip has ...   0.03 technical   0.36    0.1  human triage (team unclear)

    The last row is the confidence check at work: the model guessed technical, but at 0.36 confidence the router sends it to a person.

    The criteria section and what it means are on Choosing the Endpoint. It loads every decision model you have, so the first run takes a while.

    19 — judging images¶

    Draws solid-color PNGs with the standard library (no image gem) and asks each vision decision model what color they are, over both endpoints, with no text at all — the image is the whole input. Results are tabulated on Judging Images: Clef Flash is right everywhere; D1 Omni 600M is right over :system_one only.
